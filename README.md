# Clarify — учебный AI-чат после урока

Clarify помогает школьнику разобраться в теме занятия: ученик задаёт тему и цель, при желании добавляет заметки, а затем уточняет непонятное в чате. Ассистент получает контекст урока при каждом обращении и стремится объяснять коротко, с подсказкой или примером. Это **локальный прототип для демонстрации**, а не замена учителю или готовый публичный сервис для детей.

## ✨ Что уже работает

- Создание учебной сессии с темой, целью и необязательными заметками.
- Вопросы в чате и действия **«Объясни проще»** / **«Дай пример»** после первого ответа.
- Сохранение вопросов и ответов в SQLite; восстановление открытой сессии после обновления страницы.
- Основной AI-провайдер — Gemini; Groq используется как резерв при отсутствии ключа Gemini или временном сбое. Ошибку ключа, модели либо отказ Gemini по безопасности резервный провайдер не скрывает.
- При недоступности AI интерфейс показывает ошибку: демонстрационный текст не подставляется, незавершённая пара «вопрос–ответ» не записывается.

**Граница текущей версии:** чат возвращает только текст. Поиск, генерация и показ изображений в текущем коде не реализованы. Нет регистрации и авторизации; не развёртывайте API публично и не вводите персональные данные детей.

## 🧰 Стек и устройство

| Часть | Реализация |
| --- | --- |
| Интерфейс | `front/code.html`: HTML, CSS, JavaScript; оформление с Tailwind CSS, математические формулы с KaTeX, иконки Lucide загружаются из CDN. |
| API | Python, FastAPI, Uvicorn; HTML и API обслуживаются одним сервером. |
| AI | Серверный адаптер Gemini с резервным вызовом Groq через HTTP. |
| Данные | SQLite: сессии и упорядоченная история сообщений. |
| Настройки | `python-dotenv`, локальный `.env` с ключами на стороне сервера. |

```text
front/code.html ── /api/* ──> backend/app/main.py
                              ├── llm.py      → AI-провайдеры
                              ├── schemas.py  → проверка и формат данных
                              └── storage.py  → SQLite
```

При вопросе сервер передаёт AI тему, цель, доступные заметки и часть истории диалога. Заметки не возвращаются в ответе `GET /api/sessions/{session_id}`: клиент получает только признак `has_lesson_notes`. Идентификатор открытой сессии интерфейс хранит в `localStorage`; по нему восстанавливает историю.

## 🚀 Запуск локально

Откройте PowerShell **в корне репозитория**:

1. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

2. Создайте локальный файл настроек из образца и заполните **хотя бы один** AI-ключ (`GEMINI_API_KEY` или `GROQ_API_KEY`):

   ```powershell
   Copy-Item .env.example .env
   ```

   Значения моделей при необходимости меняются там же через `GEMINI_MODEL` и `GROQ_MODEL`. Не добавляйте секреты в исходники или Git: `.env` исключён через `.gitignore`. После изменения настроек перезапустите сервер.

3. Запустите приложение:

   ```powershell
   python -m uvicorn backend.app.main:app
   ```

4. Откройте `http://127.0.0.1:8000/` (перенаправление на `/app/code.html`). Для проверки сервера: `http://127.0.0.1:8000/api/health`; интерактивная документация API: `http://127.0.0.1:8000/docs`.

Не открывайте `front/code.html` через `file://`: интерфейс обращается к API на том же адресе, что и страница. Отдельный фронтенд-сервер и настройка CORS для обычного запуска не требуются. Локальная база по умолчанию создаётся по пути `backend/clarify.db` и исключена из Git.

## 🧪 Сценарий демонстрации

1. В интерфейсе выберите или введите тему, укажите цель и, если нужно, заметки; сохраните урок.
2. Задайте вопрос по теме. После ответа попробуйте **«Объясни проще»** или **«Дай пример»**.
3. Обновите страницу: открытая сессия и её история загрузятся из SQLite.

Для ручной проверки без интерфейса доступны маршруты:

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/health` | Проверить доступность API. |
| `POST /api/sessions` | Создать урок. |
| `GET /api/sessions/{session_id}` | Получить урок и историю. |
| `POST /api/sessions/{session_id}/messages` | Отправить вопрос (`ask`) или действие (`simplify`, `example`). |

Пример тела запроса для создания урока:

```json
{
  "topic": "Квадратичная функция",
  "objective": "Понять смещение графика",
  "lesson_notes": "Разбирали вершину параболы"
}
```

Для вопроса отправьте `{"action":"ask","text":"Почему график сдвигается вправо?"}` в маршрут сообщений с ID созданной сессии. Для действий достаточно `{"action":"simplify"}` или `{"action":"example"}`. Ответ формирует подключённый AI-провайдер; конкретная формулировка заранее не задана.

## ✅ Проверка и ограничения

Из корня проекта:

```powershell
python -m unittest discover -s backend/tests -v
```

В текущем репозитории проходят **23 теста** с подменой сетевых ответов: они проверяют HTTP-маршруты, валидацию, сохранение истории и логику переключения AI-провайдеров. Они **не подтверждают** доступность ваших ключей, внешних сервисов или работу приложения в браузере — для этого проведите сценарий выше с собственным ключом. Без настроенного рабочего провайдера запрос сообщения завершится HTTP `502`, но сессию и ранее сохранённую историю это не удалит.

Прототип рассчитан на локальный запуск: у API нет авторизации и защиты от злоупотребления. Внешние CDN интерфейса и AI-провайдеры требуют сетевого доступа; фактические ответы и доступность зависят от их работы и вашей конфигурации.
